# Retail Sales Prediction Using ANN

## Overview
This project was developed as part of the YuvaIntern Week 5 assignment on Deep Learning Applications in Data Science. It demonstrates a regression workflow using an Artificial Neural Network (ANN) and the Online Retail dataset.

## Objectives
- Preprocess retail transaction data.
- Extract date-based features.
- Build a neural network using TensorFlow/Keras.
- Train and evaluate the regression model.
- Visualize training loss and prediction results.

## Technologies
- Python
- Pandas and NumPy
- TensorFlow/Keras
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Files
- `Task5_Deep_Learning_ANN.ipynb` — notebook and implementation.
- `Task5_Deep_Learning_ANN_Report.docx` — detailed project report.
- `online_retail_cleaned.csv` — cleaned dataset, if included.
- `task5_training_loss.png` — training/validation loss visualization, if generated.
- `task5_actual_vs_predicted.png` — prediction visualization, if generated.

## Evaluation
The model is evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R-squared (R²).

Actual evaluation values should be added after successfully executing the notebook.

## Limitations
The current model uses date-derived features only. Its performance may be limited because transaction-level sales depend on additional factors. The experiment should not be treated as a production-ready forecasting system.
